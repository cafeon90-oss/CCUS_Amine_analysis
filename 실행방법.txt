====================================================
CCUS 공정 라이선스 벤치마크 툴 — 실행 방법
====================================================

[사전 준비]
Python 3.9 이상이 설치되어 있어야 합니다.

[1단계] 패키지 설치
터미널(cmd 또는 PowerShell)에서 이 폴더로 이동 후:

    pip install -r requirements.txt

[2단계] 앱 실행

    streamlit run app.py

브라우저가 자동으로 열리며 http://localhost:8501 에서 실행됩니다.

====================================================
[주요 기능]
① 종합 비교   — KoSol / MEA / MHI KS-1 We·SPECCA·COCA 비교
② 에너지 분해 — We 구성요소 (재생열 / 펌프 / 블로워 / 압축 / 액화)
③ 경제성 분석 — CAPEX·OPEX 분해, COCA 한국 기준
④ 흡수제 손실 — 배가스 조성(O₂·NOx·SOx) 기반 Arrhenius 예측
⑤ 트렌드 분석 — 문헌 24개 포인트 회귀선 (SRD↔L/G, SRD↔We)
⑥ 신기술 예측 — SRD 입력 → We·COCA 자동 추정 + 문헌 대비 위치
⑦ Custom 입력 — 직접 파라미터 입력 후 기존 라이선스와 비교

====================================================
[표준값 내장 — 입력 없어도 바로 실행 가능]
· 전기 단가     : 120 원/kWh
· LPS 스팀 단가 : 25,000 원/GJ
· MPS 스팀 단가 : 32,000 원/GJ
· 환율          : 1,350 원/USD
· 할인율        : 8%
· 설비 수명     : 25년
· 가동률        : 85%
· 배가스 발생원 : 석탄 발전소 기준
